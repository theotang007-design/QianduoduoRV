# 钱多多智能复盘

每个交易日收盘后自动采集持仓股票的行情与新闻，调用大模型做相关性与情绪判断，生成结构化复盘报告，通过本地网页查看并支持历史回溯。

> **免责声明**：本系统为信息整理与辅助分析工具，不做买卖决策。报告由程序自动抓取公开信息并结合AI辅助分析生成，仅供信息整理参考，可能存在信息遗漏、延迟或AI误判，**不构成任何投资建议**。股市有风险，投资决策及后果需由使用者自行判断和承担。

## 一、快速开始

### 1. 安装依赖

项目已内置虚拟环境 `.venv`。若需重建：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip setuptools wheel
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 2. 配置 AI API Key

**推荐方式**：启动服务后访问「设置」页面直接填写，保存后即时生效（写入 `.env`，页面只显示掩码）。

也可手动复制 `.env.example` 为 `.env`（**`.env` 已被 .gitignore 忽略，不会外传**）：

```ini
AI_PROVIDER=deepseek          # 可选 deepseek | volcengine
DEEPSEEK_API_KEY=sk-xxxxxxxx
MAX_NEWS_PER_STOCK_PER_DAY=5  # 每股每日最多分析条数，控制API成本
```

未配置 Key 时系统仍可正常采集行情与新闻、计算技术指标与波段信号，仅跳过AI消息分析（不会崩溃）。

### 3. 维护持仓

- **网页端（推荐）**：启动服务后访问「持仓管理」页
  - **买卖调仓**：直接在表格里改「数量」「成本价」，点该行「更新」即时生效
  - 新增/删除持仓在同页操作
  - 「⟳ 刷新最新价」可一键更新全部持仓的行情
  - 表格显示最新收盘价、市值、仓位占比与浮动盈亏（按最近交易日收盘价估算，仅供参考）
- **多账户**：顶栏账户下拉可切换证券账号，各账户持仓与报告相互隔离，行情与新闻全局共享（不重复消耗API额度）
- 首次使用可参考 [holdings.example.json](holdings.example.json) 批量导入（真实持仓文件 `holdings.json` 已被 gitignore）

### 4. 运行

```powershell
# 启动网页（双击也可）
.\启动网页.bat            # 然后访问 http://127.0.0.1:5000

# 手动执行一次复盘
.\每日复盘.bat            # 非交易日会自动跳过
.\每日复盘.bat --force              # 强制运行
.\每日复盘.bat --date 2026-08-07    # 补跑指定日期
```

### 5. 配置每日自动运行

以 PowerShell 运行下面的脚本，注册每天 15:30 的任务计划：

```powershell
.\注册定时任务.ps1          # 注册
.\注册定时任务.ps1 -Remove  # 卸载
```

脚本内部会判断当日是否为交易日，非交易日自动跳过。

## 二、功能对照

| 需求 | 实现 |
|---|---|
| 持仓管理 | 表格内就地修改数量/成本价，支持增删改，含市值、仓位占比与浮动盈亏参考 |
| 多账户 | 支持多个证券账号切换，持仓与报告按账户隔离 |
| 行情采集 | 日 OHLC、成交量、涨跌幅，保留最近60个交易日；另采集30分钟K线 |
| 技术指标 | MA5/MA10/MA20、MACD、RSI14、量比、BIAS20、均线偏离度 |
| 波段信号 | 阶段顶部（减仓警戒/见顶确认/假顶）与波段底部（低吸观察/止跌确认/假底）判定 |
| 新闻/公告 | 东方财富资讯搜索 + 个股公告 + **行业板块消息**，按标题去重 |
| AI分析 | 相关性/情绪倾向/事件分类/影响范围（公司或行业）/简要理由，"无关"不进报告 |
| 大白话说明 | 技术面同时给出专业解读与通俗解释，非专业用户也能看懂当前状态 |
| 报告归档 | 结构化JSON存 SQLite，永久保留 |
| 历史查询 | 按日期浏览、按个股查看近30天消息 |
| K线图表 | ECharts 蜡烛图 + 均线 + 成交量 |
| 容错 | 多数据源降级、失败重试、单点失败不中断流程 |

### 数据源降级策略

- **日线行情**：腾讯财经 → 新浪财经 → akshare，任一成功即止
- **30分钟K线**：新浪财经分钟接口，用于MACD背离判断
- **行业归属**：东方财富 push2delay → push2 双域名降级
- **新闻**：东方财富资讯 + 公告 + 行业板块消息，失败重试2次后跳过并记日志
- **AI**：失败重试3次；仍失败则**不写入结果表**，下次运行自动重试（避免误判被永久固化）

## 三、波段趋势信号

针对**业绩基本面优质**的波段标的设计，不适用于连板妖股。使用 MA20、BIAS20、RSI14、30分钟MACD 四项指标，只输出指标状态、警戒区间与确认条件，**不预测涨跌、不给买卖指令**。

### 阶段顶部 / 减仓警戒

主升浪允许指标钝化，BIAS20 高企或 RSI > 70 **不单独构成见顶依据**。

- **警戒条件**（任一命中进入观察）：BIAS20 进入过热区、MA20 由上行转走平或拐头、30分钟MACD顶背离叠加放量、RSI14 高位拐头回落
- **确认条件**（需多重共振）：收盘价连续2日跌破MA20 且 MA20 同步走平/向下；或 30分钟顶背离 + 日线放量 + RSI高位拐头三重共振
- **假顶场景**：主升浪指标长期钝化、单日放量长上影次日即收复、上升趋势中反复出现的分钟级背离、指数系统性回调带动的同步下挫

### 波段底部 / 低吸观察

**前置门槛**：MA20 必须维持向上；MA20 拐头向下则直接判定趋势转弱，放弃底部判断。

- **观察条件**：BIAS20 进入负乖离超跌区（超卖 ≠ 底部）、RSI14 进入低位区、股价回踩至MA20附近、30分钟MACD底背离（仅作线索）
- **确认条件**：量能萎缩、止跌K线形态（长下影或阳包阴）、RSI低位回升、连续2日站回MA20——四类中至少两项共振
- **输出区间**：超跌观察区间、近20日低点、止损参考阈值（近20日低点下方3%）
- **假底场景**：MA20 已向下时的任何超跌反弹、仅有分钟级背离而日线未止跌、缩量反抽无法站回MA20、跌破20日低点后的首次反弹

触发信号的股票会在**今日报告页顶部汇总提醒**，点击可跳转到个股详情查看完整三段结构。

## 四、项目结构

```
├── config.py          # 配置加载（.env / holdings.json）、AI设置读写、风险提示文案
├── compat.py          # 运行环境兼容补丁（见「已知问题」）
├── database.py        # SQLite 数据层（含多账户 schema 迁移）
├── collector.py       # 行情与新闻采集（多源降级 + 重试 + 去重）
├── technical.py       # 技术指标计算、技术面解读与大白话说明
├── signals.py         # 波段趋势信号（阶段顶部 / 波段底部判定）
├── ai_analyzer.py     # 大模型分析（相关性/情绪/分类/影响范围）
├── report.py          # 复盘报告生成与归档
├── run_review.py      # 每日主流程入口（采集→分析→报告→存库）
├── web_app.py         # Flask 本地Web服务
├── templates/         # 页面模板
├── static/logo.svg    # 系统 Logo
├── data/review.db     # SQLite 数据库（自动创建）
└── logs/              # 运行日志（按月切分）
```

### 数据表

| 表 | 用途 |
|---|---|
| `accounts` | 证券账户列表 |
| `holdings` | 持仓列表（按账户隔离） |
| `daily_quotes` | 日线行情历史（代码+日期唯一） |
| `min30_quotes` | 30分钟K线（用于MACD背离判断） |
| `news_raw` | 原始新闻/公告 |
| `news_analysis` | AI分析结果（关联 news_raw） |
| `daily_reports` | 复盘报告归档（按账户+日期） |
| `news_dates` | 采集进度标记，避免同日重复抓取 |

## 五、AI 输出约束

Prompt 中明确禁止出现「建议买入」「建议卖出」「目标价」等投资建议类措辞，仅做信息层面解读。模型返回的枚举值会经白名单校验后入库：

- 相关性：高 / 中 / 低 / 无关
- 情绪倾向：利好 / 利空 / 中性
- 事件分类：业绩 / 政策 / 行业 / 公司治理 / 突发事件 / 其他
- 影响范围：公司 / 行业

行业消息即使未点名公司，只要该公司处在受影响的产业链上也会被判定为相关，并在理由中说明传导路径。

网页与报告仅做信息陈述，不使用「买入信号」等指令化呈现。

## 六、已知问题

**本机 Python 为 3.10.0b4（beta 版本）**，标准库 `types` 模块缺少正式版才导出的 `UnionType`，会导致 `typing_extensions` / `beautifulsoup4` / `akshare` 导入失败。[compat.py](compat.py) 已在运行时补齐该属性，`config.py` 首行导入使其全局生效。

建议升级到正式版 Python 3.10+ 以彻底规避，届时 `compat.py` 会自动跳过（内部有 `hasattr` 判断），无需改动代码。
